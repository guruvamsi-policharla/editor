editor

An agent-agnostic editor for reviewing what a coding agent changed, inline.

Built on VSCodium. Agent edits show up in the file with Keep and Undo on every change. editor contains no AI and calls no models: you bring your own agent, including the Codex or Claude Code extensions or any harness that writes files.
