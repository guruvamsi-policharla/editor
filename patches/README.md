# patches/

Core patches against VS Code. They're applied by VSCodium's `prepare_vscode.sh` from its `patches/user/` directory, after all of VSCodium's patches. `fork/scripts/prepare-vscodium.sh` copies them there, with the ones in `patches/<os>/` for the OS being built. VSCodium's own patches differ per OS (`patches/linux/`, `patches/osx/` in its repo), so a patch whose context includes a line from one of those applies on that OS only: `fork/scripts/check-patches.sh` applies the series for macOS and Linux. Base: VS Code 1.135.0 @ `08d4889f` plus the VSCodium patches at the ref in `fork/upstream.env`.

**Regenerating:** in a prepared tree, reverse-apply our patches (`git apply -R`, last one first, including the ones in `patches/<os>/`) and commit that state as a base. Re-apply the patches, make your edits, then run `git add -N src/vs/workbench/contrib/agentReview` and `git diff HEAD -- <paths> > patches/9x-….patch`. Copy the new files back into `fork/src/`. Run `fork/scripts/check-patches.sh` before pushing: a tree prepared on Linux has VSCodium's Linux patches in it, so a diff made there can fail on macOS. CI runs that script on PRs; the manual `full-checks.yml` also typechecks the patched tree.
